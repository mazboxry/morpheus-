# 味方モンスターの行動ロジック 現状調査と今後の展望

## 1. 概要
本プロジェクトにおけるモンスターの行動ロジックは、現在**「演出用の縦スライス実装（Tweenベース）」**と、**「将来統合予定の個別ユニット実装（`CharacterBody3D`ベース）」**の2つのレイヤーが存在しています。

---

## 2. 現在の実装状況

### A. 現行デモフロー (`scenes/showcase_main.gd`)
現在画面上で動作しているモンスターの挙動です。

```
[物理ダイス停止] -> [着地点から召喚] -> [初期配置へ整列] -> [敵城へTween進軍]
```

* **生成・配置 (`_make_unit` / `_on_dice_results_ready`)**:
  * 出目（レアリティ）に応じたシリンダー形状の `MeshInstance3D` を動的生成。
  * ダイスの着地点から味方整列位置（`destination`）へスケールアップしながらTween移動。
* **進軍ロジック (`_start_march`)**:
  * `Tween` による座標補間アニメーション。
  * Z軸方向にサイン波で揺れながら、X軸方向は `Battlefield/Castles/EnemyCastle` の座標（城の手前）に向けて前進。
  * ※現時点では当たり判定やHP、戦闘処理は持たない演出用ロジックです。

---

### B. 単体ユニットの骨格実装 (`scenes/units/monster.gd` / `monster.tscn`)
将来的にゲームループへ統合される、自律行動ユニットのベースコードです。

* **基本ステータス**:
  * `hp` / `max_hp`（レアリティに応じてスケーリング）
  * `attack_power`（レアリティに応じてスケーリング）
  * `speed`（移動速度）
  * `attack_cooldown`（攻撃間隔）
* **行動ステート（`_physics_process`）**:
  1. **非会敵時 (`target == null`)**:
     * `_move_forward()`: `velocity = Vector3(0, 0, -1) * speed` で直進 (`move_and_slide()`)。
  2. **会敵時 (`target != null`)**:
     * 立ち止まり、クールダウンごとに `_attack()` を実行してターゲットの `take_damage()` を呼び出す。
     * 20%の確率でスキル発動（自身へヘイスト付与、または敵へ毒付与）。
* **索敵・ターゲット認識 (`scenes/units/monster_hitbox.gd`)**:
  * `Area3D`（Hitbox）の `body_entered` により、相手チームの `body` を検知すると自動的に `target` に設定。
* **死亡判定 (`die`)**:
  * HPが0になると `died` シグナルを発行して `queue_free()`。

## 3. 将来どのタイミングで移行・変更していくか

| フェーズ | タイミング | 変更内容 |
| :--- | :--- | :--- |
| **フェーズ 1（直近）** | 敵モンスターのテスト出現 | 演出用Tweenから、`scenes/units/monster.tscn`（CharacterBody3D）の実体スポーンへ切り替え。 |
| **フェーズ 2** | 会敵・戦闘の最小実装 | 移動中のモンスター同士が `Hitbox` で接触した際に停止し、ダメージを与え合うループを接続。 |
| **フェーズ 3** | 城攻撃・目標切り替え | 敵モンスターがいない場合は敵城（EnemyCastle）をターゲットとして認識し、城へ攻撃するルーチンを追加。 |
| **フェーズ 4** | ナビゲーション・障害物回避 | 単純直進から、`NavigationAgent3D` による地形・障害物・他ユニットの回避ルート移動へ拡張。 |

## 4. 放置ゲームとしての行動ロジックカスタマイズ（プレイバリューの可能性）

放置系・タワーディフェンスのゲーム性を高めるため、モンスターの行動ロジック自体をプレイヤーが育成・構築・カスタマイズできる拡張案です。

### 1. ガンビット / 作戦方針（AIスロット）
モンスターやダイスごとに「行動優先度」をセットできる仕組み：
* **城特攻（突撃型）**: 敵を無視して城へ最速直進。
* **迎撃型（護衛型）**: 接近した敵や味方後衛を狙う敵を優先排除。
* **援護型（バッファー/ヒーラー）**: 前衛の背後に留まり、回復やヘイストを付与。

### 2. ダイスの出目・セットに応じたAI/スキル分岐
* 出目（1〜6）やダイスの種類に応じて「攻撃モード」「防御モード」「範囲スキルモード」など行動パターンが変化。
* ダイスデッキ構築（どの出目でどのAIが動くか）が戦略要素に。

### 3. 状態異常・シナジービルド
* 毒特効（毒状態の敵に大ダメージを与えるAI）。
* ノックバック・足止め・引き寄せなど、地形やトラップと組み合わせた陣形構築。
